# savetgchat

Юзербот Telegram на вашем аккаунте. Он входит в уже идущий голосовой эфир без микрофона и пишет разговор в wav. Отдельно умеет сохранить профиль и список диалогов в PostgreSQL Neon.

Локальный PostgreSQL не нужен. Библиотеки ставятся только в `.venv`.

## Установка

Из каталога, куда клонирован репозиторий:

```bash
git clone https://github.com/mahmudproduction/savetgchat.git
cd savetgchat
chmod +x install.sh
./install.sh
```

Скрипт по очереди спрашивает:

1. API ID и API hash с [my.telegram.org](https://my.telegram.org)
2. Номер телефона
3. Облачный пароль, если включена двухэтапная проверка, и подсказку Telegram
4. Строку подключения [Neon](https://console.neon.tech)

Пароль и строка базы вводятся скрыто и попадают только в `.env`. Затем скрипт создаёт `.venv`, ставит библиотеки из `requirements.txt` и может включить пользовательскую службу `savetgchat`.

На другой машине тот же результат делает Cursor: откройте проект и выполните промпт из [CURSOR_PROMPT.md](CURSOR_PROMPT.md).

## Первый вход

Код приходит в Telegram на указанный номер.

```bash
.venv/bin/python userbot.py --code 12345
```

Если облачный пароль уже записан в `.env`, отдельный вопрос в терминале не нужен. Сессия хранится в `userbot.session` и в Git не входит.

## Запись эфира

В чате, где голосовой уже запущен, отправьте со своего аккаунта:

| Команда | Действие |
| --- | --- |
| `!str` | Войти без микрофона и писать звук в `log/call_<id>.wav` |
| `!str 0` | Закрыть файл и выйти из эфира |

Статус приходит в Избранное. `!str 0` не завершает звонок для остальных. Заголовок wav дописывается в момент остановки, поэтому файл удобно слушать после `!str 0`.

Звук пишется как PCM 48000 Гц, стерео, 16 бит. На небольшом эфире Telegram не отдаёт куски stream mode, поэтому запись идёт через WebRTC.

## База

`export_user.py` один раз снимает профиль и диалоги в таблицу `userbot`: где аккаунт участник, где админ, где создатель. Текст переписок не сохраняется.

Подключение всегда проверяет сертификат Neon (`sslmode=verify-full`).

## Служба

```bash
systemctl --user status savetgchat
systemctl --user restart savetgchat
```

Код выхода `2` означает, что нужен вход, и служба сама не перезапускается. Ctrl+C в ручном запуске останавливает процесс без traceback.

## Что не попадает в Git

`.env`, `.venv`, `userbot.session` и каталог `log/` с записями эфира. Шаблон переменных лежит в `.env.example`.
