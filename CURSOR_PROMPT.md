# Промпт для Cursor

Открой этот репозиторий в Cursor и отправь агенту весь текст ниже, начиная со строки «Установи проект». Если файл уже открыт в проекте, достаточно написать: «выполни промпт из CURSOR_PROMPT.md».

---

Установи проект savetgchat на этой машине сам. Пользователь не должен копировать команды: спрашивай у него только секреты и код входа Telegram.

Репозиторий: https://github.com/mahmudproduction/savetgchat

## Что сделать

1. Работай в каталоге этого репозитория. Если его ещё нет на диске, клонируй `https://github.com/mahmudproduction/savetgchat.git` в каталог, который назовёт пользователь, иначе в `~/savetgchat`.
2. Если `.venv` ещё нет, создай его командой `python3 -m venv .venv`. Нужен Python 3.10 или новее. Системный Python пакетами не засоряй.
3. Установи библиотеки так: `.venv/bin/pip install --upgrade pip` и `.venv/bin/pip install -r requirements.txt`.
4. Если нет файла `.env`, спроси значения по одному и запиши их только в `.env` с правами `600`. В чат, в коммиты и в журнал значения не копируй.
   - API ID. Это число с https://my.telegram.org, раздел API development tools.
   - API hash. Ввод можно скрыть.
   - Номер телефона в виде `+` и цифры.
   - Облачный пароль. Сначала спроси, включена ли двухэтапная проверка. Если да, спроси подсказку, которую показывает Telegram, затем пароль дважды. Если нет, оставь `TELEGRAM_PASSWORD` и `TELEGRAM_PASSWORD_HINT` пустыми.
   - Строку подключения Neon. Она начинается с `postgresql://` или `postgres://`. Её берут в console.neon.tech → Connect.
5. Шаблон `.env`:

```
DATABASE_URL=
TELEGRAM_BOT_TOKEN=
TELEGRAM_API_ID=
TELEGRAM_API_HASH=
TELEGRAM_PHONE=
TELEGRAM_PASSWORD=
TELEGRAM_PASSWORD_HINT=
```

6. Каталоги `log`, `img`, `incl`, `tpl` создай, если их нет. Записи эфира остаются в `log/`.
7. Спроси, нужен ли автозапуск. Если да, создай пользовательскую службу systemd `savetgchat.service`: рабочий каталог — корень проекта, команда — `.venv/bin/python -u userbot.py`, `Restart=on-failure`, `SuccessExitStatus=2`. Включи её через `systemctl --user enable --now`. Службу другого пользователя не трогай.
8. Первый запуск без сессии попросит код из Telegram. Попроси пользователя прислать код в чат Cursor и запусти `.venv/bin/python userbot.py --code КОД`. Код в репозиторий не записывай. Облачный пароль бери из `.env`.
9. Проверь `systemctl --user is-active savetgchat.service` или, если автозапуск не включали, что `userbot.py` доходит до строки ожидания.

## Как пользоваться после установки

- В чате, где уже идёт голосовой эфир, своим сообщением отправь `!str`. Юзербот входит без микрофона и пишет звук в `log/call_<id>.wav`.
- `!str 0` закрывает wav и выходит из эфира. Для остальных участников звонок не завершается.
- Статус команд приходит в Избранное, не в общий чат.
- Снимок профиля и списка диалогов: `.venv/bin/python export_user.py`. Текст сообщений туда не входит.

## Чего не делать

- Не коммить и не показывать `.env`, `*.session`, код входа, пароль и строку Neon.
- Не ставь пакеты через sudo, если хватает `.venv`.
- Не создавай новый голосовой эфир. Вход только в уже идущий.
- Не вызывай завершение эфира для всех. Выход только свой, командой `!str 0`.
- Если `.env`, `.venv` и служба уже работают, секреты не перезаписывай. Напиши, что установка уже сделана.
